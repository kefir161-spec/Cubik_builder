# Cubik Builder — Web 3D-конфигуратор / редактор

**Демо (последняя версия):** https://cubik.one/builder/  
**Репозиторий (код):** https://github.com/kefir161-spec/Cubik_builder  

Web-3D конфигуратор модульных интерьерных изделий. Пользователь собирает продукт в редакторе и получает конфигурацию, которая используется в заказе и производственном пайплайне.

## Что умеет

- **Интерактивный 3D-редактор (WebGL)**: рендер сцены в реальном времени и управление объектами в браузере  
- **Параметрическая конфигурация**: логика модульной сборки (правила/ограничения), редактируемые параметры продукта  
- **UI вокруг 3D**: панели инструментов, контролы параметров, состояния, подсказки/онбординг  
- **Управление состоянием проекта**: сохранение/восстановление конфигураций, сериализация сцены  
- **Undo / Redo**: история изменений для безопасных итераций  
- **Autosave**: автосохранение прогресса пользователя  
- **Интеграция с продажами/производством**:
  - маппинг конфигурации → продукт / SKU (логика комплектации)
  - генерация превью (thumbnails)
  - экспорт артефактов (например, PDF-инструкции — если включено)

## Моя роль / зона ответственности

**Полная end-to-end разработка (solo):**
- идея и продуктовая концепция
- архитектура фронтенда и реализация
- **UX/UI редактора** (сценарии, взаимодействия, структура интерфейса)
- **верстка и стилизация UI (HTML/CSS)**: лэйаут, адаптивность, состояния, компоненты интерфейса
- рендер-пайплайн и оптимизация производительности
- интеграции с backend API (сохранение/загрузка, экспорт, заказ)
- тестирование и итеративное развитие

Дополнительно:
- участвую в обсуждении product roadmap (что делать дальше, приоритизация)
- управляю дизайнерами, которые делают **рендеры новых продуктов**: постановка задач и контроль качества
- проверяю **техническую корректность 3D-моделей** и соответствие визуала производственным ограничениям

## Технологии

- **HTML, CSS** (адаптивная верстка, UI вокруг canvas/WebGL)
- **JavaScript**
- **WebGL / Three.js**
- Интеграции с **REST API** (backend-сервисы)
- Сериализация и сохранение состояния на клиенте
- Современные подходы разработки, включая AI-ассистированное программирование для ускорения итераций (прототип → production)

## Структура проекта (ключевые модули)

> Названия файлов могут отличаться в зависимости от сборки, но логика разделена по зонам ответственности:

- `renderer.*` — сцена/камера/рендер-цикл, загрузчики, материалы, оптимизация  
- `ui.*` — UI редактора, взаимодействия, обработчики событий  
- `history.*` — undo/redo (история действий)  
- `autosave.*` — автосохранение и восстановление  
- `io.*` — импорт/экспорт, сериализация  
- `backend-api.*` — слой API и интеграции  
- `thumbnail.*` — генерация превью  
- `pdf-instructions.*` — экспорт инструкций (если включено)  
- `tutorial.*` / `mobile.*` — онбординг и мобильная адаптация

## Зачем это бизнесу

Конфигуратор используется как **self-service инструмент продаж**:
- повышает конверсию за счёт интерактивной визуализации и персонализации
- снижает нагрузку на пресейл/менеджеров
- автоматизирует передачу конфигурации в заказ и производство
